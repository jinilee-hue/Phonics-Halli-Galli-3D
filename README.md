# Phonics Halli Galli 3D (WebGL 시제품)

원래 게임(`../Phonics-Halli-Galli`)은 그대로 두고, **게임 판 · 종 · Coco를 WebGL(three.js) 3D로** 다시 그린 시제품이에요.

- 공유 주소: **https://jinilee-hue.github.io/Phonics-Halli-Galli-3D/**
  - main에 올리면 1~2분 뒤 바뀌어요. 파일을 10분 동안 저장해 두는 브라우저가 있어서, 바로 안 보이면 잠시 뒤 새로고침.
- 저장소: https://github.com/jinilee-hue/Phonics-Halli-Galli-3D (공개 · 원래 게임 저장소와 따로)

## 여는 법
- `실행.command` 더블클릭 → http://localhost:5182 (원래 게임 5181과 같이 켜 둘 수 있어요)
- 또는 `index.html` 더블클릭 (그림을 코드 안에 넣어 둬서 서버 없이도 돌아가요)
- 교실 태블릿에서: https://jinilee-hue.github.io/Phonics-Halli-Galli-3D/?fps — 왼쪽 아래에 초당 장면 수 · 화질이 보여요
  (맥과 같은 와이파이라면 `http://(맥 주소):5182/?fps`도 돼요)

## 무엇이 3D이고 무엇이 그대로인가
| 3D (WebGL) | 원래 HTML 그대로 |
|---|---|
| 탁자(두께 · 솟은 테두리 · 천 느낌 · 바닥 그림자) | 게임 규칙 · Coco 빠르기 · 단어 목소리 · 배경 음악 |
| 나 / Coco 칸(두께), 카드 더미(카드 7장 두께) | 말풍선 · 위 버튼 · 시간 · 소리 막대 · 다시 듣기 |
| 나온 카드: 더미에서 집어 → 뒤집으며 날아와 → 착 (진짜 그림자) · 2 · 3단계 글자 카드도 | 인트로 영상 · 시작 화면 글자 · 돌아가는 카드 · 결과 화면 |
| 맞히면: 색 테두리 · 바닥 빛 · 반짝이 · 카드가 S 칸으로 날아감 · S 동전 톡 | 내 차례 손 · 흰 점선 · 종 울릴 때 알록달록 물결 |
| **종** (`gl/bell3d.js`): 노란 몸통 · 빨간 2단 받침 · 은색 목 · 꼭지, 표정(깜빡 · 윙크 · 활짝 · 앗) · 눌림 · 숨쉬기 | |
| **Coco** (`gl/coco3d.js`): 분홍 손종 · 고리 · 얼굴 창 · 작은 팔다리, 표정 8가지 · 땀방울, 몸짓(숨쉬기 · 통통 · 흔들 · 종 쪽으로 기울기) | |

## 손(마우스 · 손가락) 따라 움직이기
| 무엇 | 어떻게 |
|---|---|
| 공간 | 손 쪽으로 보는 자리(카메라)가 살짝 옮겨 가요 → 탁자 · 칸 · 카드 · 종 · Coco가 입체로 엇갈려 움직이고, 방 배경(맨 뒤)도 같이 |
| 빛 | 해도 손 쪽으로 살짝 → 그림자가 손을 따라 기울어요 |
| 종 | 눈이 손 쪽을 보고, 몸도 손 쪽으로 살짝 돌고 끄덕여요 |
| Coco | 눈동자가 손 쪽을 보고(생각 · 준비 · 놀람 · 시무룩일 땐 원래 눈) 몸도 돌아요. 손가락 · 마우스로 콕 누르면 통통 튀며 눈웃음 (게임에는 영향 없음) |
| 내 카드 더미 | 내 차례에 마우스를 올리면 맨 위 카드가 살짝 들리고 마우스 쪽으로 기울어요 |
- 마우스는 4초, 손가락은 2.5초 동안 안 움직이면 천천히 제자리로 돌아가요. 마우스가 창 밖으로 나가도 제자리로.
- 시점이 옮겨 가도 HTML 판이 같이 움직여서(CSS perspective-origin) 누르는 자리 · 내 차례 손 · 말풍선이 그대로 맞아요.
- 기기에서 '동작 줄이기'를 켜 두면 공간 · 몸은 안 움직이고 눈만 따라가요.

## 360° 돌려 보기 (`gl/view360.js`)
| 하는 것 | 어떻게 돼요 |
|---|---|
| 판 위 빈 곳을 좌우로 끌기 | 판 전체가 빙글 (화면 폭만큼 끌면 약 한 바퀴) · 놓으면 미끄러지다 멈춤 |
| 판 위 빈 곳을 위아래로 끌기 | 아래로 = 바로 위에서 내려다보기 · 위로 = 탁자 높이에서 옆으로 보기 (탁자 밑으로는 안 내려가요) |
| 두 손가락 벌리기 · 마우스 휠 | 가까이 · 멀리 |
| Coco(게임) · 종(시작 화면)을 끌기 | 캐릭터만 한 바퀴: 좌우로 끌면 빙글 · 위아래로 끌면 앞뒤 공중돌기 → 놓으면 스르르 정면으로 |
| Coco를 콕 | 통통 + 눈웃음 |
| 오른쪽 위 360° 버튼 | 정면이면 한 바퀴 빙 둘러보고 돌아와요 · 돌아가 있으면 정면으로 |
| 빈 곳 두 번 톡 · 시작 ↔ 게임 화면 바뀔 때 | 정면으로 |
- 돌려 둔 채로도 게임이 그대로 돼요: HTML 판(.felt)에 같은 CSS 회전을 걸어서 누르는 자리 · 내 차례 손 · 점선이 3D와 같이 돌아요.
- 종 · Coco HTML 그림판(말풍선 · 시작 화면 카드 궤도 자리)은 판이 돈 만큼 되돌려서 늘 원래 모습으로 캐릭터를 따라가요.
- 좌우로 돌리면 해는 방에 그대로라 그림자가 판 위에서 돌아가고, 위아래는 보는 눈만 움직이는 거라 해는 판에 그대로예요(위에서 · 낮게 봐도 어두워지지 않음).
- 캐릭터가 젖히는 쪽 · 양은 위아래를 뺀 판에서 정해요. 그래서 바로 위에서 내려다봐도 뒤집히지 않고 정수리가 보이고, 낮게 볼수록 똑바로 서요.

## 어떻게 맞춰 그리나
- `gl/board3d.js`가 HTML 판(`#table` 안)의 자리 · 크기 · 상태(class)를 매 순간 읽어서 같은 자리에 3D로 그려요.
- 카메라를 `.scene`의 CSS 원근(perspective 1500px, 시점 50% -10%)과 똑같이 맞춰서, 3D 물건이 HTML 자리에 정확히 겹쳐요.
  그래서 누르는 자리 · 말풍선 · 해상도 대응은 원래 코드 그대로 맞아요.
- 종 · Coco의 표정은 원래 `src/bell-face.js` · `src/coco-face.js`가 정하는 값(data-eyes 등)을, 몸짓은 원래 CSS 움직임 값을 읽어서 그대로 따라 해요.
- 게임 카메라는 탁자를 약 60° 위에서 내려다봐서, 종 · Coco는 원래 그림 각도(종 28° · Coco 12°)로 보이게 받침 앞을 축으로 살짝 뒤로 젖혀 세워요(원래 HTML 그림도 카메라를 향해 세운 그림이었어요). 그래서 탁자는 바닥 그림처럼 먼저 깔아요.
- 얼굴은 원래 그림 조각(눈 · 입 · 볼 · 얼굴 창)을 카메라 쪽에서 비춰 입혀서 그림처럼 반듯하게 보여요.
- 바뀐 게 없으면 그리지 않고, 숨쉬기 · 깜빡임만 있을 땐 초당 30장만 그려요(배터리 · 발열 아낌).

## 기기 성능 대비 (태블릿 · 전자칠판)
| 화질 | 선명도 | 그림자 | 화소 한도 |
|---|---|---|---|
| high | 최대 2배 | 부드러움 | 약 420만 |
| mid | 1.5배 | 보통 | 약 260만 |
| low | 1배 | 가벼움 | 약 160만 |
- 그래픽 칩 이름으로 처음 화질을 정하고(CPU로 그리는 기기는 low), 카드가 움직이는 동안 실제 속도를 재서 느리면 한 단계씩 내려요.
- low에서도 너무 느리면(초당 18장 미만) **원래 HTML 판으로 자동으로 바뀌어요**. 이 결정은 기기에 7일 동안 기억해요.
- 그래픽 오류(WebGL context lost)가 나도 원래 판으로 바뀌어요. WebGL을 못 쓰는 기기는 처음부터 원래 판이에요.
- 시험용 주소: `?q=high` · `?q=mid` · `?q=low`(화질 고정) · `?q=html`(3D 끔) · `?fps`(속도 표시)
- 이 맥(M5 Pro)에서 아이패드 크기(2360×1640) high: 한 장면 0.43ms. 교실 기기에서는 `?fps`로 확인해 주세요.

## 원래 게임을 고쳤을 때
- `동기화.command` 더블클릭 (또는 `python3 tools/sync_from_original.py`)
  - 원래 게임의 `src/` 전부 · 쓰는 그림 · `index.html`(3D 줄만 끼워서)을 가져와요. 카드 그림이 바뀌었으면 3D 그림(`src/gl-tex.js`)도 다시 만들어요.
- Coco 그림(`assets/coco.png` → 조각)이 바뀌었으면: `python3 tools/build_coco_face.py` → `python3 tools/build_gl_tex.py`

## 파일
| 파일 | 내용 |
|---|---|
| `gl/board3d.js` | 3D 판 · 카메라 · 화질 단계 · 원래 판으로 바꾸기 |
| `gl/bell3d.js` | 3D 종 |
| `gl/coco3d.js` | 3D Coco |
| `gl/view360.js` | 360° 돌려 보기 (끌기 · 두 손가락 · 휠 · 360° 버튼) |
| `gl/board3d.css` | 3D가 켜지면 HTML 판 · 종 · Coco를 안 보이게(자리 계산용으로만 둠) |
| `vendor/three/three.iife.js` | three.js r186 (MIT) — 더블클릭으로도 열리게 일반 스크립트로 묶은 것 |
| `src/gl-tex.js` | 3D 그림(카드 앞 · 뒷면, S 동전, 종 · Coco 얼굴 조각) — `tools/build_gl_tex.py`가 만듦 |
| `tools/sync_from_original.py` | 원래 게임에서 가져오기 |
| `tools/build_coco_face.py` | Coco 얼굴 창 그림 오리기 |
| `src/*` 나머지 · `assets/` | 원래 게임에서 복사, **고치지 않음** |

## 아직 안 한 것

- Coco 다리는 넓은 치마 테에 가려 통통 뛸 때만 살짝 보여요
