# Phonics Halli Galli 3D (WebGL 시제품)

원래 게임(`../Phonics-Halli-Galli`)은 그대로 두고, **게임 판 · 종 · Coco를 WebGL(three.js) 3D로** 다시 그린 시제품이에요.

- 공유 주소: **https://jinilee-hue.github.io/Phonics-Halli-Galli-3D/**
  - main에 올리면 1~2분 뒤 바뀌어요. 파일을 10분 동안 저장해 두는 브라우저가 있어서, 바로 안 보이면 잠시 뒤 새로고침.
- 저장소: https://github.com/jinilee-hue/Phonics-Halli-Galli-3D (공개 · 원래 게임 저장소와 따로)

## 여는 법
- `실행.command` 더블클릭 → http://localhost:5182 (원래 게임 5181과 같이 켜 둘 수 있어요)
- 또는 `index.html` 더블클릭 (그림을 코드 안에 넣어 둬서 서버 없이도 돌아가요)
- 교실 태블릿에서: https://jinilee-hue.github.io/Phonics-Halli-Galli-3D/?fps — 왼쪽 아래에 초당 장면 수 · 화질이 보여요
  (맥과 같은 와이파이라면 `http://(맥 주소):5182/?fps`도 돼요)

## 무엇이 3D이고 무엇이 그대로인가
| 3D (WebGL) | 원래 HTML 그대로 |
|---|---|
| 탁자(두께 · 솟은 테두리 · 천 느낌 · 바닥 그림자) | 게임 규칙 · Coco 빠르기 · 단어 목소리 · 배경 음악 |
| 나 / Coco 칸(두께), 카드 더미(카드 7장 두께) | 말풍선 · 위 버튼 · 시간 · 소리 막대 · 다시 듣기 |
| 나온 카드: 더미에서 집어 → 뒤집으며 날아와 → 착 (진짜 그림자) · 2 · 3단계 글자 카드도 | 인트로 영상 · 시작 화면 글자 · 돌아가는 카드 · 결과 화면 |
| 맞히면: 색 테두리 · 바닥 빛 · 반짝이 · 카드가 S 칸으로 날아감 · S 동전 톡 | 내 차례 손 · 흰 점선 · 종 울릴 때 알록달록 물결 |
| **종** (`gl/bell3d.js`): 캐릭터 시트(GAME BELL) · JSON 사양대로 — 아랫단이 퍼지는 노란 돔 · 도넛 받침 · 회색 축 · 버섯 버튼, 무광 클레이, 표정(깜빡 · 윙크 · 활짝 · 앗) · 눌림 · 숨쉬기 | |
| **Coco** (`gl/coco3d.js`): 분홍 손종 · 고리 · 얼굴 창 · 작은 팔다리, 표정 8가지 · 땀방울, 몸짓(숨쉬기 · 통통 · 흔들 · 종 쪽으로 기울기) | |

## 손(마우스 · 손가락) 따라 움직이기
| 무엇 | 어떻게 |
|---|---|
| 공간 | 손 쪽으로 보는 자리(카메라)가 살짝 옮겨 가요 → 탁자 · 칸 · 카드 · 종 · Coco가 입체로 엇갈려 움직이고, 방 배경(맨 뒤)도 같이 |
| 빛 | 해도 손 쪽으로 살짝 → 그림자가 손을 따라 기울어요 |
| 종 | 눈이 손 쪽을 보고, 몸도 손 쪽으로 살짝 돌고 끄덕여요 |
| Coco | 눈동자가 손 쪽을 보고(생각 · 준비 · 놀람 · 시무룩일 땐 원래 눈) 몸도 돌아요. 손가락 · 마우스로 콕 누르면 통통 튀며 눈웃음 (게임에는 영향 없음) |
| 내 카드 더미 | 내 차례에 마우스를 올리면 맨 위 카드가 살짝 들리고 마우스 쪽으로 기울어요 |
- 마우스는 4초, 손가락은 2.5초 동안 안 움직이면 천천히 제자리로 돌아가요. 마우스가 창 밖으로 나가도 제자리로.
- 시점이 옮겨 가도 HTML 판이 같이 움직여서(CSS perspective-origin) 누르는 자리 · 내 차례 손 · 말풍선이 그대로 맞아요.
- 기기에서 '동작 줄이기'를 켜 두면 공간 · 몸은 안 움직이고 눈만 따라가요.

## 종 모형 (`gl/bell3d.js`) — 캐릭터 시트 · JSON 사양
| 부분 | 모양 (받침 반지름 = 1, 받침 바닥 가운데 = 원점) | 색 (JSON) |
|---|---|---|
| 받침 | 곧은 옆 · 도넛처럼 둥근 위 테두리 · 넓고 살짝 오목한 윗면 · 오목한 바닥 접시, 높이 .30 | #E02E35 |
| 돔 | 아랫단이 둥글게 퍼지는 반구 (테 바닥 .385 ~ 꼭대기 1.30), 받침에서 살짝 떠 있고 가운데 회색 기둥 · 속은 빔 | #FFEB00 |
| 축 | 원기둥 (1.30 ~ 1.42 보임), 누르면 돔 속으로 쑥 | #8A8A8A (무광 회색) |
| 버튼 | 동글납작한 버섯 (1.42 ~ 1.55), 누르면 같이 쑥 | #FFD400 |
| 얼굴 | 원래 그림 조각, 시트 정면처럼 입은 눈 아래 끝 높이 · 볼은 눈 바깥 아래 | 눈 · 입 #4A2B21 · 볼 #FF9999 |

- 단면은 시트 그림의 실루엣을 직접 재서 정했어요 (시트의 d1 · d2 표시는 그림마다 달라서). 게임 화면 빛에서 색이 JSON 값과 맞는지 재 봤어요(노랑 255·233·24 · 빨강 206·50·55).

## 360° 돌려 보기 (`gl/view360.js`)
| 하는 것 | 어떻게 돼요 |
|---|---|
| 판 위 빈 곳을 좌우로 끌기 | 판 전체가 빙글 (화면 폭만큼 끌면 약 한 바퀴) · 놓으면 미끄러지다 멈춤 |
| 판 위 빈 곳을 위아래로 끌기 | 아래로 = 바로 위에서 내려다보기 · 위로 = 탁자 높이에서 옆으로 보기 (탁자 밑으로는 안 내려가요) |
| 두 손가락 벌리기 · 마우스 휠 | 가까이 · 멀리 |
| Coco(게임) · 종(시작 화면)을 끌기 | 캐릭터만 한 바퀴: 좌우로 끌면 빙글 · 위아래로 끌면 앞뒤 공중돌기 → 놓으면 스르르 정면으로 |
| Coco를 콕 | 통통 + 눈웃음 |
| 오른쪽 위 360° 버튼 | 정면이면 한 바퀴 빙 둘러보고 돌아와요 · 돌아가 있으면 정면으로 |
| 빈 곳 두 번 톡 · 시작 ↔ 게임 화면 바뀔 때 | 정면으로 |
- 돌려 둔 채로도 게임이 그대로 돼요: HTML 판(.felt)에 같은 CSS 회전을 걸어서 누르는 자리 · 내 차례 손 · 점선이 3D와 같이 돌아요.
- 종 · Coco HTML 그림판(말풍선 · 시작 화면 카드 궤도 자리)은 판이 돈 만큼 되돌려서 늘 원래 모습으로 캐릭터를 따라가요.
- 좌우로 돌리면 해는 방에 그대로라 그림자가 판 위에서 돌아가고, 위아래는 보는 눈만 움직이는 거라 해는 판에 그대로예요(위에서 · 낮게 봐도 어두워지지 않음).
- 캐릭터가 젖히는 쪽 · 양은 위아래를 뺀 판에서 정해요. 그래서 바로 위에서 내려다봐도 뒤집히지 않고 정수리가 보이고, 낮게 볼수록 똑바로 서요.

## 결과 화면 (`gl/result-fx.css` · `gl/result-fx.js`, 3D 폴더에만)
- 하얀 판 → 3D 보드판처럼: 도톰하게 솟은 테두리(2.2vh) 안쪽 바닥이 쑥 들어가 있어요(위쪽 안벽 그늘 · 아래쪽 안벽 빛). 맞힌 종 · 빠르기 · 실수 칸은 보드판의 S 칸처럼 한 번 더 들어가고, 순위 줄은 바닥 위에 놓인 카드처럼 볼록. 색은 따뜻한 크림, 왼쪽 판은 이기면 버터색 · 지면 살구색.
- 순위는 3등까지. 내가 3등 밖이면 3등 밑에 내 줄(4등보다 아래면 사이에 '···'). 3등 안이면 세 줄만, 크게. '예시 · 연동 전' · '게임 끝 · 1단계 · 5세' 꼬리표와 '모은 S가 많은 순 · 같으면 빠른 순' 줄은 뺐어요(반 친구 기록은 아직 예시 자료).
- 글자색: 갈색 글자는 모두 #111(큰 글자 · 숫자 · 이름) · #333(작은 글자 · 이름표)으로. '나' → 'Me', '다시 하기' → 'Play again'(Fredoka). 제목도 영어로: 이겼다! → You win! · 아쉬워요! → Good try! (종이 하는 말과 같게, 좁은 화면에선 한 줄에 맞게 글자를 줄임).
- '나는 우리 반 N등 / N명' 칸 대신 가운데에 동그란 프로필 그림만 (등수는 아래 순위 줄에). 지금은 기본 그림 `gl/media/profile_default.svg` — 아이 프로필 그림이 생기면 이 파일만 바꾸면 돼요(또는 result-fx.js의 PROFILE_SRC).

| | 이겼을 때 | 졌을 때 |
|---|---|---|
| 제목 | 글자가 통통 튀어 올라와 출렁 | 떨어져서 시무룩 기울었다가 다시 벌떡 |
| S 토큰 | 판의 S 칸에서 날아와 쏙 (내 것은 도 · 미 · 솔) | Coco 것 먼저 (낮고 작은 소리) |
| 왕관 | '나' 이름 옆 | 'Coco' 이름 옆 |
| 그 밖 | 꽃가루 · 판을 누르면 꽃가루 톡 | 판을 누르면 하트 · 다시 하기가 콩콩 |
| 함께 | 숫자 올라가기 · 내 프로필 그림이 톡 → 내 줄 반짝(3등 안이면 메달 반짝) · 토큰 · 왕관 · 프로필 · 순위 줄을 누르면 흔들 · 다시 하기 숨쉬기 | |
- 원래 결과 화면(`src/result.js`)은 그대로 두고 덧입혀요. main.js가 처음 읽힐 때 renderResult를 가져가서, `result-fx.js`는 result.js 바로 뒤에 읽어요(동기화 스크립트의 RESULT_ADD). '동작 줄이기'면 움직임 없이 바로 보여요.

## 노란 종 튜터 (`gl/tutor.js` · `gl/tutor.css` · `gl/tutor-voice.js`, 3D 폴더에만)
종이 진행자 겸 선생님이 되어 게임을 이끌어요. 원래 게임 코드는 고치지 않고 게임 함수(flip · hitBell · end …)를 감싸서 끼어들어요. 끄려면 주소 뒤에 `?tutor=off`.
- 종은 말로만 해요 — 말풍선은 화면에 안 보여요(사용자 요청). 말하는 동안 입이 움직이고 몸짓을 해요. 글은 화면 읽기 도구에만 읽혀요.
- 목소리: 짧은 영어, 5살쯤 아이 목소리 — 낱말을 읽는 아이 목소리(Ana)를 살짝 높게(약 330Hz · 5살 아이 높이). 30% 높였을 땐 '너무 아기 같다'고 해서 낮췄어요. 받아쓰기 17/18. `tools/build_tutor_voice.py`로 18줄을 미리 만들어 둠(파일을 더블클릭해 열어도 소리 남). 말을 고치려면 그 파일의 LINES만 고치고 다시 돌려요.
- 낱말 소리를 가리지 않아요(C-05): 종은 낱말 읽기가 끝나고 비는 틈에만 말하고, 낱말이 시작되면 바로 멈춰요. 종이 말하는 동안은 Coco가 기다려요(반응 · 카드 넘기기를 잠시 멈췄다가 이어서).
- 한 번에 한 명만: 종이 말할 땐 Coco 말풍선은 쉬고, 아이가 종을 치거나 카드를 넘기면 종은 바로 멈춰요. 한국어 안내 글('한 개면 치지 마!' 등)은 종의 말 · 몸짓으로 바꿨어요.

| 상황 | 종 |
|---|---|
| 게임 시작 · 다시 하기 | 콩콩 + "Ready? Go!" |
| 내 차례인데 머뭇 | 내 카드 더미를 바라보며 갸웃 + "Your turn!" (두 번까지) |
| (처음 몇 장) 여럿 카드 | 반짝 · 콩콩 + 양옆 알록달록 물결 + 카드 위에 S가 톡 + "Ring the bell!" — 안 치면 4초 뒤 한 번 더, 그래도 안 치면 Coco 차례 |
| 그때 종 대신 카드를 넘기면 | 막고 "Wait! Ring the bell first!" (말은 한 번, 그다음은 콩콩 · 반짝만) |
| (처음 몇 장) 하나 카드 | 도리도리 + "Just one. Don't ring!" |
| 맞힘 | 끄덕 + "Yes!" · "Great job!" · "Super!" · "You got it!" (번갈아) · S 2개째면 "One more!" |
| 하나 카드에 침 | 도리도리 + "Oops! Just one." |
| Coco가 먼저 맞힘 | Coco 쪽을 보며 "Listen for the s sound!" (한 판에 2번까지) · Coco S 2개째면 "Listen carefully!" |
| Coco가 먼저 친 뒤에 침 | "Coco was first!" |
| Coco가 하나 카드에 침 | 도리도리 + "Oops, Coco! Just one." (한 판에 한 번) |
| 아무도 안 친 여럿 카드 | 다음 카드 전에 "That was more than one! Ring next time." (한 판에 2번까지) |
| 끝 | 이기면 콩콩 + "You win! Great job!" · 지면 끄덕 + "Good try! Let's play again!" |

- 잘하면 물러나요: 첫 판 처음 몇 장(여럿 2장 · 하나 1장, 최대 6장)은 자세히 → 그다음은 반응만 → 3번 연속 맞히면 말없이 끄덕만. 2번 연속 틀리면 다음 2장은 다시 자세히.
- 가볍게 단계에서 여럿 카드에 머뭇거리면 말없이 콩콩 · 반짝.
- 3D가 꺼져도(HTML 종) 말 · 말풍선 · 몸짓이 돼요. '동작 줄이기'면 몸짓 · 물결 없이 말과 말풍선만.
- Coco 말풍선도 영어로 (`gl/coco-en.js`): Hi! · I'm Coco! · More than one! · So fast! · Oops! · I win! · One more game? · You win! — 원래 게임의 한국어 말은 그대로 두고 보여 줄 때만 바꿔요.

## 어떻게 맞춰 그리나
- `gl/board3d.js`가 HTML 판(`#table` 안)의 자리 · 크기 · 상태(class)를 매 순간 읽어서 같은 자리에 3D로 그려요.
- 카메라를 `.scene`의 CSS 원근(perspective 1500px, 시점 50% -10%)과 똑같이 맞춰서, 3D 물건이 HTML 자리에 정확히 겹쳐요.
  그래서 누르는 자리 · 말풍선 · 해상도 대응은 원래 코드 그대로 맞아요.
- 종 · Coco의 표정은 원래 `src/bell-face.js` · `src/coco-face.js`가 정하는 값(data-eyes 등)을, 몸짓은 원래 CSS 움직임 값을 읽어서 그대로 따라 해요.
- 게임 카메라는 탁자를 약 60° 위에서 내려다봐서, 종 · Coco는 원래 그림 각도(종 28° · Coco 12°)로 보이게 받침 앞을 축으로 살짝 뒤로 젖혀 세워요(원래 HTML 그림도 카메라를 향해 세운 그림이었어요). 그래서 탁자는 바닥 그림처럼 먼저 깔아요.
- 얼굴은 원래 그림 조각(눈 · 입 · 볼 · 얼굴 창)을 카메라 쪽에서 비춰 입혀서 그림처럼 반듯하게 보여요.
- 바뀐 게 없으면 그리지 않고, 숨쉬기 · 깜빡임만 있을 땐 초당 30장만 그려요(배터리 · 발열 아낌).

## 기기 성능 대비 (태블릿 · 전자칠판)
| 화질 | 선명도 | 그림자 | 화소 한도 |
|---|---|---|---|
| high | 최대 2배 | 부드러움 | 약 420만 |
| mid | 1.5배 | 보통 | 약 260만 |
| low | 1배 | 가벼움 | 약 160만 |
- 그래픽 칩 이름으로 처음 화질을 정하고(CPU로 그리는 기기는 low), 카드가 움직이는 동안 실제 속도를 재서 느리면 한 단계씩 내려요.
- low에서도 너무 느리면(초당 18장 미만) **원래 HTML 판으로 자동으로 바뀌어요**. 이 결정은 기기에 7일 동안 기억해요.
- 그래픽 오류(WebGL context lost)가 나도 원래 판으로 바뀌어요. WebGL을 못 쓰는 기기는 처음부터 원래 판이에요.
- 시험용 주소: `?q=high` · `?q=mid` · `?q=low`(화질 고정) · `?q=html`(3D 끔) · `?fps`(속도 표시)
- 이 맥(M5 Pro)에서 아이패드 크기(2360×1640) high: 한 장면 0.43ms. 교실 기기에서는 `?fps`로 확인해 주세요.

## 원래 게임을 고쳤을 때
- `동기화.command` 더블클릭 (또는 `python3 tools/sync_from_original.py`)
  - 원래 게임의 `src/` 전부 · 쓰는 그림 · `index.html`(3D 줄만 끼워서)을 가져와요. 카드 그림이 바뀌었으면 3D 그림(`src/gl-tex.js`)도 다시 만들어요.
- Coco 그림(`assets/coco.png` → 조각)이 바뀌었으면: `python3 tools/build_coco_face.py` → `python3 tools/build_gl_tex.py`
